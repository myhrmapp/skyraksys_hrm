# SkyrakSys HRM — API Reference

Generated by deep-analysis of `backend/routes/`, `backend/middleware/`, and `backend/server.js`.  
All routes require authentication unless marked `[PUBLIC]`.

---

## Authentication

### Auth Routes `/api/auth`
| Method | Path | Access | Description |
|--------|------|--------|-------------|
| POST | `/api/auth/login` | PUBLIC | Login with email + password. Returns access token in httpOnly cookie |
| POST | `/api/auth/refresh` | PUBLIC | Rotate refresh token using JTI validation |
| POST | `/api/auth/logout` | Auth | Blacklist current JTI, clear cookies |
| GET | `/api/auth/profile` | Auth | Get current user profile |
| PUT | `/api/auth/change-password` | Auth | Change own password |

## Authorization Model

```
RBAC Hierarchy:
  admin  >  hr  >  manager  >  employee
  
Data Access (canAccessEmployee middleware):
  admin  → ALL employees
  hr     → ALL employees  
  manager→ self + direct reports
  employee → self ONLY
```
